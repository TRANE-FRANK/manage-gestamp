# Stack Tecnológico

## Objetivo

Manage Gestamp utiliza tecnologías modernas enfocadas en rendimiento, mantenibilidad y escalabilidad.

---

# Frontend

## Next.js

Framework principal para el desarrollo de la aplicación.

### Razones de uso

- App Router.
- Server Components.
- Route Handlers.
- Excelente rendimiento.
- Escalable para proyectos grandes.

---

## React

Biblioteca para construir interfaces de usuario reutilizables.

### Razones de uso

- Componentes reutilizables.
- Ecosistema maduro.
- Integración nativa con Next.js.

---

## TypeScript

Lenguaje utilizado en todo el proyecto.

### Razones de uso

- Tipado estático.
- Mejor autocompletado.
- Detección temprana de errores.
- Código más mantenible.

---

## Tailwind CSS

Framework CSS utilizado para el diseño de la interfaz.

### Razones de uso

- Desarrollo rápido.
- Diseño responsive.
- Componentes consistentes.
- Fácil personalización.

---

# Backend

## Server Actions

Utilizadas para operaciones del negocio como:

- Crear registros.
- Actualizar información.
- Eliminar registros.
- Subir documentos.

---

## Route Handlers

Utilizados para exponer recursos mediante una API REST.

Ejemplos:

- Visualizar PDF generado.
- Visualizar PDF firmado.

---

# Base de Datos

## PostgreSQL

Motor de base de datos principal.

### Razones de uso

- Robusto.
- Confiable.
- Excelente rendimiento.
- Soporte para transacciones.

---

## Prisma ORM

ORM utilizado para acceder a PostgreSQL.

### Razones de uso

- Tipado automático.
- Migraciones.
- Relaciones sencillas.
- Excelente integración con TypeScript.

---

# Documentos

## ExcelJS

Biblioteca utilizada para generar documentos de Excel a partir de plantillas.

### Uso

- Llenado automático de responsivas.
- Conservación del formato original.

---

## LibreOffice

Utilizado para convertir archivos de Excel a PDF.

### Razones de uso

- Conversión local.
- Mantiene el formato.
- No depende de servicios externos.

---

# Gestión de Paquetes

## pnpm

Administrador de paquetes utilizado en el proyecto.

### Razones de uso

- Instalaciones rápidas.
- Menor uso de espacio.
- Excelente rendimiento.
