# Prioridad Actual

Las próximas tareas del proyecto son:

1. Completar el detalle del empleado.
2. Completar el detalle del equipo.
3. Implementar Dashboard.
4. Implementar Mantenimientos.
5. Implementar Garantías.
6. Agregar autenticación y roles.
7. Generar reportes.
8. Incorporar auditoría y notificaciones.

---

# Objetivo Final

Construir una plataforma integral para la gestión de activos de TI que permita administrar de forma centralizada:

- Empleados.
- Equipos.
- Asignaciones.
- Documentación.
- Mantenimientos.
- Garantías.
- Reportes.
- Auditoría.

Manteniendo una arquitectura limpia, escalable y preparada para el crecimiento futuro.
